# Glyphkiln

Glyphkiln is a monorepo for deterministic, code-rendered business graphics.
It keeps the rendering engine independently publishable while the self-hostable
application consumes only its documented public API.

## Workspaces

- [`packages/glyphkiln-core`](packages/glyphkiln-core/) — the Apache-2.0
  `@glyphkiln/core` SDK and `glyphkiln` CLI.
- [`apps/glyphkiln-app`](apps/glyphkiln-app/) — the non-published application
  foundation, built with the Next.js App Router.
- [`examples/style-showcase`](examples/style-showcase/) — a runnable consumer
  project that turns one inert design document into reviewed SVG, PNG, and
  provenance outputs.

The repository-level Apache-2.0 license preserves the existing project license.
Review the intended long-term application license before distributing
`glyphkiln-app` separately.

## Use the web application

New users should follow the
[Glyphkiln App local guide](apps/glyphkiln-app/README.md#run-the-app-locally).
It covers PostgreSQL, migrations, the first-owner token, the render worker, and
the first design export.

Start by cloning the repository and installing its pinned dependencies:

```bash
git clone https://github.com/xxibcill/glyphkiln.git
cd glyphkiln
npm ci
```

The app guide continues from this point. Do not expose the development server
to a network or skip its database and storage setup.

## Develop the repository

Use Node.js 22.22.2 or newer within the Node 22 release line, or Node.js 24 or
newer, with npm 10.9.8. The repository's `.nvmrc` selects the tested Node 22
development version.

If your npm version differs, install npm 10.9.8 globally while your shell is in
a directory outside this checkout; npm enforces the repository toolchain before
running project commands.

```bash
npm ci
npm run dev
```

`npm run dev` builds Core first, then starts the app at
[`http://localhost:3000`](http://localhost:3000). Complete the app guide's
database, migration, environment, and storage steps first. Run the separate
render worker when testing durable exports.

Run the complete verification suite from the repository root:

```bash
npm run build
npm run typecheck
npm run lint
npm test
npm run test:coverage
```

Build and run the production application locally:

```bash
npm run build
npm start
```

Core-specific verification commands remain available at the root:

```bash
npm run text-layout-data:verify
npm run fixtures:verify
npm run examples:verify
npm run licenses:verify
npm run test:package-consumer
```

Generate the committed Core examples and the standalone style showcase with:

```bash
npm run examples:generate
```

The showcase uses the public `@glyphkiln/core` API, a fixed seed, and a pinned
manifest timestamp. Its verification command compares every generated byte so
it also serves as a compact end-to-end determinism check.

See the [implementation plan](docs/full-implementation-plan.md) and
[monorepo decision](docs/adr/0010-glyphkiln-monorepo.md) for the product and
repository boundaries.
