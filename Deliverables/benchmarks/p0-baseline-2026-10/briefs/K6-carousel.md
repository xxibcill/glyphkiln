# K6 — Six-slide placement carousel

[All briefs](README.md) · [Scoring sheet](scoring-sheet.md)

| Field                             | Value                                                                                                                                   |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Viewer task                       | Swipe through a short guide and learn where to place the lamp                                                                           |
| Message                           | Choose the moment, then place one lamp at the desk, bedside, or entry, leaving room for the shade.                                      |
| Relationship that should carry it | Sequence: hook → choose → three places → placement rule → mood by place → action; each frame advances one step                          |
| Wrong interpretation to avoid     | Six unrelated posters; a product spec sheet                                                                                             |
| Canvas / format                   | Six slides, 1080×1440 (TikTok organic Photo Mode working canvas, with the repository's interface overlay as a safe zone)                |
| Delivery view                     | 360×480 per slide; review all five adjacent pairs                                                                                       |
| Proposed time box                 | 4 hours                                                                                                                                 |
| Comprehension question            | “Where does the guide suggest placing the lamp, and what should you leave room for?” Correct: desk, bedside, entry; room for the shade. |

1. Any change, omission, or reordering of the fixed copy
2. Text that cannot be read at the delivery view size (judged on the delivered-size proof, not the master)
3. Text clipped, overflowing, or colliding with another element
4. Product silhouette cropped through a defining feature (lamp shade, cobalt base, finial) where the product appears
5. An invented claim, testimonial, statistic, price, or product feature
6. Slide order or slide count changed
7. Any copy within the platform interface overlay zones
8. The lamp never visible in the sequence
