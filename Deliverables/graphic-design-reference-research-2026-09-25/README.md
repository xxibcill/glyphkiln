# Real-world graphic design reference library

**120 distinct projects · 11 work categories · 18 style families · 22 primary-source domains**

Researched 25 September 2026 for Glyphkiln. This library expands the evidence base before further design work. It includes commissioned identities, published books and magazines, client packaging, deployed campaigns, information graphics, and environmental systems. Each project counts once, regardless of how many images or applications its case study shows.

Open the [searchable catalogue](index.html), the [sortable CSV](references.csv), or the [complete source records](references.json). Every catalogue entry includes a project link, creator, client, format and style tags, source evidence, and a proposed Glyphkiln stress test. The original visuals remain on the linked project pages.

## Method and verification

- Each specific primary project page was opened and its project text read. Sources are the creating studio, participating designer, publisher, or commissioning organization. Search snippets and generic portfolio homepages do not qualify as project verification.
- Commission, publication, or deployment evidence is recorded for every entry. Studio case studies are first-party claims; commercial effectiveness and client approval were not independently audited.
- Speculative/student redesigns were excluded. MACBA was excluded when the source explicitly identified several applications as fictitious. A film-focused KFC entry was replaced with a campaign containing explicit outdoor graphic applications.
- Different commissions for one client count separately: for example, Spotify’s core identity, Pollen artwork, Summer 2023 advertising, and Music + Talk each have their own source and deliverable brief.
- Style families are research classifications, not objective rankings or claims that a whole project belongs to one historical movement. Detailed source-derived style descriptors remain in the records.
- Country context describes the client, deployment, or cultural context when the source supports it. It is not automatically the studio’s location.
- Verification scope: **120 source-checked; 7 additionally inspected visually**. The remaining 113 entries have source-supported notes and are ready for deeper visual review. No pixel-level comparison of all 120 is claimed.
- The sample favors studios with accessible, documented case studies and is weighted toward Europe and North America. Asian and multilingual examples broaden it, but it is not a representative global census.
- Copyright stays with the original creators. This collection supplies attribution and project links; it does not supply reusable client artwork or licenses.

## Research findings for the next stress-test plan

1. **Variation is a production requirement.** Personalized recap screens and location-dependent campaigns require reliable input substitution, layout adaptation, and batch output. See [LinkedIn Year in Review](https://buck.co/work/linkedin-year-in-review) and [Uber Eats: Iftar Incoming](https://www.motherlondon.com/work/uber-eats-iftar-incoming).
2. **Format changes affect the idea itself.** Cropping a mark can communicate direction, rotating a product can exploit a wide placement, and empty newspaper space can become the message. See [McDonald's: Follow the Arches](https://www.cossette.com/fr/blogue/cossette-et-mcdonalds-deconstruisent-les-emblematiques-arches-dor-pour-guider-les-consommateurs-vers-le-restaurant-le-plus-pres), [KFC: Vertically Gifted](https://www.motherlondon.com/work/kfc-tower), and [WSJ: Missing Articles](https://www.motherlondon.com/work/wsj).
3. **Print introduces material and structural constraints.** Covers, wrappers, labels, stamps, and folding collateral need checks beyond a single canvas. Start with [Gagosian Quarterly redesign](https://graphicthoughtfacility.com/gagosian-quarterly/), [Kungfu Pu’er Tea packaging](https://www.designbridge.com/work/kungfu-puer), and [Agatha Christie commemorative stamps](https://studio-sutherland.co.uk/projects/agatha-christie.php).
4. **Typography must support language and context.** Arabic/Latin branding, Korean campaign type, and road signage need different reading-distance and script tests. See [Rakbank identity](https://koto.com/projects/rakbank), [Nike Women Korea VaporMax](https://dasoljung.com/new-project), and [South Korean Road Signage](https://studiodumbar.com/work/south-korean-road-signage).
5. **Information design needs a semantic contract.** Charts, narrative data graphics, legends, and dense references must preserve the underlying meaning as well as the visual system. See [Nike Viz System](https://datalands.co/work/nike-viz), [IBM Data Visualization Guidelines](https://www.pentagram.com/work/ibm-data-visualization-guidelines), and [Science Stack: Tools Within Reach](https://www.pentagram.com/work/science-stack-tools-within-reach).
6. **Motion and spatial work expose separate output requirements.** Timing, sound, surfaces, fabrication, and viewing distance cannot be established by a successful static preview. See [Comedy Central Idents](https://studiodumbar.com/work/comedy-central) and [Grand Palais Wayfinding](https://2x4.org/work/grand-palais/).

These observations define candidate briefs. The per-entry `glyphkiln_test` field proposes a capability exercise; it does not assert that Glyphkiln currently supports that deliverable.
